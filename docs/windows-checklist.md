| # | 手順 | 期待する結果 | 結果 |

| 1-1 | ローカルフォルダ（OneDrive 外）のブックをデスクトップ版で開く | サイドバーに鍵マーク、Build / Sync が押せない | |

## 6. インストーラー

| # | 手順 | 期待する結果 | 結果 |
|---|---|---|---|
| 6-1 | `xlCode-Setup-1.0.0.exe` を実行 | 「自分だけ / すべてのユーザー」とインストール先を選べる | |

## 7. OneDrive の同期状態（D）

xlCode は Windows のシェルプロパティ `System.SyncTransferStatus` とファイル属性を PowerShell 経由で読んで同期状態を判定している。
**値の意味は Windows 上で未確認。** ステータスバーの「OneDrive: 〜」をクリックすると、出力パネルに生の値（`attrs` / `sts` / `sps`）が出るので、各場面の値を記録する。

| # | 場面 | 期待する表示 | 出力の生の値 | 結果 |
|---|---|---|---|---|
| 7-1 | 何もしていない（同期済み） | OneDrive: 同期済み | | |
| 7-2 | Build / Sync の直後（アップロード中） | アップロード待ち / 同期中 → 同期済み | | |
| 7-3 | OneDrive を一時停止 | 同期が一時停止中。Build 時に確認が出る | | |
| 7-4 | OneDrive を終了 | OneDrive: 起動していません | | |
| 7-5 | ブックを「オンラインのみ」にする | オンラインのみ | | |
| 7-6 | Web 版で編集 → 閉じる → すぐ Build | 「Web 版での編集が、まだこの PC に届いていない可能性」→「届くまで待つ」で、届いたら自動で続行 | | |
| 7-7 | エディタで編集 → 「Webで開く」 | Sync → アップロード完了を待つ → ブラウザで最新の内容が開く | | |
| 7-8 | 2 台の PC で同じブックを編集 | 複製（ブック名-PC名.xlsx）ができたら警告が出る | | |

判定がずれていたら、生の値を添えて報告する（`src/main/syncStatus.ts` の `interpret` を直す）。
